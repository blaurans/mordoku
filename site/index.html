      Comment jouer

      Un meurtre a eu lieu. Placez chaque personne sur la scène : une seule personne par ligne, une seule par colonne.

      Les cartes des suspects sont des contraintes, pas des hints. Les meubles, les zones colorées et les cases hachurées comptent autant que les cases vides.

      Une fois la scène complète, le meurtrier est la personne restée seule avec la victime dans la même zone.

      • 1…9 choisir une personne
      • clic sur une case : placer
      • X marquer une case impossible
      • C marquer une position possible
      • Ctrl+Z annuler · Ctrl+Maj+Z rétablir
      • P pause · T thème · H indice
